# Фирменный знак

<img src="spike/spike-256.png" width="128" alt="Storm Machine">

**Всплеск** — ровная линия измерения и один разряд посреди неё. То, ради чего продукт
существует: поймать выброс, который в среднем не виден.

## Что где лежит

| Папка | Что это |
|-------|---------|
| `spike/` | **Знак продукта.** Иконка приложений, окна, значка в трее |
| `alert/` | Тот же знак красным — состояние значка в трее, когда алерт поднят |
| `bolt/` | Отвергнутый вариант: классическая молния |
| `threshold/` | Отвергнутый вариант: всплеск с порогом и красной вершиной |
| `candidates.png` | Лист сравнения всех вариантов в настоящих размерах |

В каждой папке — `.ico` со всеми размерами, `.png` от 16 до 256 и `.svg` для документов.

Рабочие копии, которые подставлены в сборку, лежат в
[`src/StormMachine.App/Assets`](../src/StormMachine.App/Assets): `storm.ico` и
`storm-alert.ico`. Их берут иконкой все три исполняемых файла и ресурсом — окно и трей.

## Почему знак рисуется кодом

Три причины, и все три — про то, чтобы он не разъехался с продуктом.

**Размеры.** Знак отдаётся в семи размерах от 16 до 256, и уменьшение большой картинки
до шестнадцати пикселей даёт кашу. Мелкие размеры рисуются своей геометрией: рябь
на линии исчезает, поле сужается, толщина растёт. Шестнадцать пикселей — не «мелкий
случай», а основной: столько знак занимает в панели задач.

**Цвета.** Берутся из палитры интерфейса. Поменяется акцентный синий — знак пересоберётся,
а не останется от прошлой версии.

**Пересоздаваемость.** Знак, который нечем пересоздать, через год становится
неприкасаемым: его боятся трогать, потому что исходника нет.

## Пересобрать

```
cd tools\logo
dotnet run -c Release -- ..\..\assets
```

Дальше подставить выбранный вариант:

```
copy assets\spike\spike.ico src\StormMachine.App\Assets\storm.ico
copy assets\alert\alert.ico src\StormMachine.App\Assets\storm-alert.ico
copy assets\spike\spike-256.png src\StormMachine.App\Assets\storm-256.png
```

Генератор в решение намеренно не входит: он запускается руками, когда знак меняется,
а собирать его в CI незачем.

## Формат `.ico`

Мелкие размеры лежат несжатым DIB, крупные — PNG. Windows 10 и 11 понимают PNG в любом
размере, но проводник и старые диалоги исторически ждали DIB, и у иконки, собранной
целиком из PNG, есть привычка не показываться то тут, то там. Смешанный формат —
общепринятое решение этого.
