# Спайк-10 · Захват без Npcap: встроенный в Windows pktmon

**Вопрос.** Npcap продукту недоступен — лицензия NPSL запрещает его распространять
([R-02](../../docs/02-research.md)), а ставить его руками согласится не каждый.
Значит, уровень 2 у большинства мёртв. Есть ли у драйвера захвата замена, которую
не нужно ни покупать, ни распространять, ни просить поставить?

**Ответ: есть, и она уже стоит на машине.** `pktmon` — встроенный в Windows монитор
пакетов, появился в Windows 10 1809, подписан Microsoft, входит в систему. Ставить
нечего. Он умеет всё, что продукту нужно от уровня 2, и ни байта сверх того.

## Что проверено на живой сети

Стенд: Windows 11 Pro 26200, Hyper-V, физическая карта Realtek 2.5GbE, за ней
два коммутатора. Два прогона: 25 с на всех картах и 35 с на одном компоненте.

| Вопрос | Ответ |
|--------|-------|
| Фильтр по ethertype для LLDP | `-d 0x88CC` — принят, в таблице фильтров показан как `LLDP` |
| Фильтр по адресу для CDP | `-m 01-00-0C-CC-CC-CC` — принят |
| Фильтр по порту для DHCP | `-t UDP -p 67` — принят |
| Сколько стоит запуск | драйвер поднимается за **107–112 мс** |
| Что на выходе | `etl2pcap` даёт pcapng, linktype 1 (Ethernet), кадры целиком |
| **Понимает ли их наш разборщик** | **да, 0 неопознанных из 28 кадров — ни строчки правок** |
| Без прав администратора | код возврата **5**, «Отказано в доступе» — опознаётся однозначно |

Что услышано за 25 секунд нашим же `FrameParser`:

```
Соседей: 3
  Cdp:  SW-2.5G-1  порт bridge1/ether13
  Lldp: SW-2.5G-1  порт ether13
  Cdp:  SW-HW-Ext  порт bridge1/ether20
Серверов DHCP: 1
  192.168.200.1 предлагает 192.168.200.98, шлюз 192.168.200.1
```

Это ровно то, ради чего уровень 2 и существует: свой порт на коммутаторе и кто
в сегменте раздаёт адреса. Без Npcap, без покупки, без установки.

## Главная находка: один пакет приходит несколько раз

Первый прогон слушал все сетевые карты (`--comp nics`) и дал **21 полный дубль
по байтам из 25 кадров**. Причина видна в `pktmon list`:

```
   ИД MAC-адрес         Имя
   50 34-5A-60-CE-68-F7 vEthernet (DefaultVirtLan)
   56 34-5A-60-CE-68-F7 Realtek Gaming 2.5GbE Family Controller #3
```

**Один и тот же MAC у двух компонентов** — физическая карта и виртуальный коммутатор
Hyper-V поверх неё. pktmon регистрирует пакет в каждой точке стека, через которую тот
прошёл, и один кадр превращается в три-четыре.

Второй прогон слушал один компонент (`--comp 50`) — дублей стало **0**. Но вместе
с дублями пропал и **LLDP**: его кадры идут на зарезервированный адрес `01-80-C2-00-00-0E`,
который виртуальный коммутатор дальше не передаёт. На физической карте (`56`) они есть.

**Отсюда правило выбора:** слушать **все компоненты с нашим MAC** и **снимать дубли
по байтам**. Выбирать «правильный» компонент нельзя — на хосте с Hyper-V правильных
два, и каждый слышит своё.

## Чего pktmon не даёт

- **Имён интерфейсов в pcapng.** В файле один блок IDB без опций: какой компонент
  принёс кадр, после преобразования не узнать. Значит, компонент выбирается
  **до** захвата, а не разбирается после.
- **Потока в реальном времени.** Работа такая: запустить, подождать, остановить,
  преобразовать, прочитать файл. Шкала прогресса по известной длительности —
  честная, покадровая выдача — нет.
- **Работы без прав администратора.** Драйвер общается только с администратором.
  У Npcap то же самое, только там это ещё и зависит от того, как его поставили.

## Что из этого следует для продукта

1. **Второй источник захвата, а не замена.** Npcap, если он на машине есть, остаётся
   предпочтительным: он даёт кадры потоком и не гоняет их через файл. pktmon — то,
   что работает у всех остальных, то есть у большинства.
2. **Разбор общий.** `FrameParser` понимает кадры обоих источников байт в байт —
   он переезжает в отдельный проект `plugins/StormMachine.Capture.Frames`.
3. **Экран возможностей меняет совет.** Вместо «поставьте Npcap, мы его
   не распространяем» — «перезапустите от администратора»: это совет, который
   человек может выполнить, не ставя ничего.

## Запуск

```
dotnet run --project spikes/spike-10-pktmon/Spike10.csproj -c Release -- 35
dotnet run --project spikes/spike-10-pktmon/Spike10.csproj -c Release -- разбор <файл.pcapng>
```

Первый — от администратора, второй прав не требует.
