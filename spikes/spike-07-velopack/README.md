# Спайк-07 · Velopack под обрезкой

**Вопрос.** Работает ли Velopack в опубликованном виде продукта — self-contained,
`PublishSingleFile`, `PublishTrimmed`?

**Почему спрашиваем.** Ровно этот вопрос убил Quartz в [спайке-06](../spike-06-scheduler/):
библиотека, читающая JSON рефлексией, после обрезки молчит и возвращает пустоту —
без единого предупреждения на сборке. Проверять такое на отладочной сборке бесполезно:
она не обрезана и всегда скажет «всё хорошо». Velopack тоже читает ленту обновлений
из JSON, и цена ошибки здесь выше: сломанное авто-обновление не чинится обновлением.

**Как проверяли.** Настоящая цепочка целиком, на опубликованном бинарнике:

```
dotnet publish -p:SpikeVersion=1.0.0 -o pub100     # 16,4 МБ, один файл, обрезан
dotnet publish -p:SpikeVersion=1.0.1 -o pub101
vpk pack --packId Spike07 --packVersion 1.0.0 --packDir pub100 --outputDir rel
vpk pack --packId Spike07 --packVersion 1.0.1 --packDir pub101 --outputDir rel
unzip rel100/Spike07-win-Portable.zip -d portable
portable/current/spike07.exe download rel
```

## Результат: проходит

| Что проверяли | Итог |
|---------------|------|
| Разбор ленты `releases.win.json` обрезанным бинарником | 3 записи, версии и типы прочитаны верно |
| Определение установки (`VelopackLocator`) | `IsInstalled = true`, текущая версия `1.0.0` |
| Сравнение версий, поиск обновления | найдено `1.0.1` |
| Скачивание, сверка контрольной суммы, сборка из разностного пакета | `100%`, `packages/Spike07-1.0.1-full.nupkg` собран |
| Предупреждения обрезчика (`TrimmerSingleWarn=false`) | нет |

Разностный пакет между 1.0.0 и 1.0.1 — **2,7 КБ** против 9,9 МБ полного.

Применение обновления делает `Update.exe` — он написан на Rust, к .NET и обрезке
отношения не имеет, и сломать его обрезчик не может по построению.

## Что из этого следует

Velopack берём. Это первый случай, когда внешняя библиотека прошла проверку
на обрезку — и он показывает, что правило «не доверяй, а измерь» работает в обе
стороны: Quartz отвергли по измерению, Velopack принимаем по нему же.

**Авто-обновление при этом не будет молчаливым.** Продукт — измерительный инструмент;
подменить его версию посреди суточного мониторинга значит разорвать ряд измерений
надвое и не сказать об этом. Поэтому: проверка — сама, установка — по команде
оператора, и никогда во время работающего прогона. То же правило, что у профилей
окружения: узнать можно молча, поменять — нет.
