# Обозначения, единицы и термины — разбор и план правки

> Составлен по указанию оператора после осмотра собранного клиента: «непонятно вообще
> какие пороги, что это такое, в чём измеряется… даже на тесте скорости непонятно,
> в мбит или мбайтах… очень много англицизмов, тупо использованных, но не переведённых».
> Разбор сплошной: 20 файлов разметки, 40 моделей представления и все источники строк,
> которые приходят на экран извне. Здесь и находки, и решение по каждому — то, чем
> правка будет сверяться.

## Три системных дефекта

Большинство отдельных находок — следствие трёх причин, и чинить надо их.

### 1. Единица теряется по дороге на экран

`ProbeFact.Number` кладёт число в `Value`, а единицу — в отдельное поле `Unit`.
Все модели фактов клиента это поле выбрасывали: `FactRow` и `InspectFactRow`
принимают только текст значения. Итог: **«Средняя скорость 94.3»** на экране против
**«Средняя скорость 94.3 Мбит/с»** в консоли — на одном и том же прогоне.

Мегабиты это или мегабайты, продукт на экране не отвечал **нигде**.

### 2. Подпись таблицы рядов была прибита к миллисекундам

`Времена в миллисекундах.` стояло литералом под таблицей прогонщика — для любой пробы.
У пробы скорости ряды в мегабитах в секунду, и это не отсутствие единицы, а **неверная
единица**: продукт объявлял мегабиты миллисекундами.

### 3. Единого места, где решается «как показать число», не было

Форматирование миллисекунд написано шестью копиями: в «Задержке» с единицей,
в хопах «Анализа пути» без, в журнале без, в прогонщике без, в шагах сценария
с оглядкой на порог, в инспекторах так же. Одна и та же медиана показывалась
тремя способами: `12.345 мс`, `12.345`, `12 мс`.

**Решение по всем трём:** единица берётся у измерения (`MeasurementUnit`), а называет
её один словарь — `Domain/Measurements/Units.cs`, общий у консоли и окна. Написан он
был ещё в И-24 и клиентом не использовался ни разу.

## Правила, по которым правим

1. **У числа на экране всегда есть единица** — либо рядом с ним, либо в подписи
   таблицы, к которой оно относится. Второе предпочтительнее в колонках: единица
   у каждого из сорока чисел превращает таблицу в частокол.
2. **Единицу выбирает измерение, а не место показа.** Никаких «мс» литералом
   в разметке страницы.
3. **Аббревиатура расшифровывается там, где встречается впервые на странице** —
   в подсказке поля или в карточке «почему так». Расшифровка в другом разделе
   не считается: оператор читает тот экран, который открыл.
4. **Внутренние ключи не показываются.** `ping`, `trace`, `speedtest`, `dns` —
   имена для базы и консоли; на экране у пробы есть `Title`.
5. **Англицизм остаётся, только если он профессиональный термин**, которым
   пользуется сетевой инженер (джиттер, хоп, MAC, DNS). Тогда он объясняется один раз
   и дальше употребляется как есть. Всё прочее переводится.
6. **Одно понятие — одно слово.** «Порог» сейчас означает пять разных вещей;
   так быть не должно.

## Словарь: как продукт называет вещи

Решение по каждому спорному термину. Левая колонка — что было, правая — что делаем.

### Оставляем как профессиональный термин, объясняем один раз

| Термин | Как объясняем при первом появлении |
|--------|-------------------------------------|
| джиттер | «джиттер — дрожание задержки: насколько неровно приходят ответы (RFC 3550)» |
| хоп | «хоп — узел на пути пакета» |
| MAC | «MAC — аппаратный адрес сетевой карты» |
| DNS, TLS, HTTP | расшифровываются в описании инспектора |
| SNMP | «SNMP — опрос сетевого оборудования по стандартному протоколу» |
| ICMP | «ICMP — служебный протокол, которым работает ping» |
| ARP | «ARP — опрос соседей по локальной сети на втором уровне» |
| VPN, NAT, STUN | расшифровка в карточке «почему так» на своей странице |
| cron | «расписание cron: пять полей…» — расшифровка уже есть, оставляем |
| p50 / p95 / p99 | «медиана (p50)», «95-й перцентиль (p95)» — словарь `MetricWording` |
| MOS | «оценка речи MOS, шкала 1–5» |
| PDV | «разброс задержки (PDV): p99 минус медиана» |
| RTT | «время оборота (RTT)» — подпись оси графика |
| SLA | «уровень услуги (SLA)» |
| iperf3, M-Lab, Npcap, DB-IP | имена собственные, поясняются рядом |

### Переводим

| Было | Стало |
|------|-------|
| сэмпл | **сырое измерение** (во множественном — «сырые измерения») |
| агрегаты | **сводки** («прогоны со сводками») |
| Run Drawer | **панель операций** (так она и подписана в окне) |
| loopback | **петля на себя** |
| вендор | **производитель** |
| таймаут | **предел ожидания** |
| ping-sweep | **обход диапазона пингом** |
| webhook | **вызов по адресу (webhook)** |
| гистерезис | **запас на снятие** |
| бюджет ошибок | остаётся, но с расшифровкой: «сколько простоя допускает цель» |
| both / download / upload | **обе стороны / приём / отдача** |
| ред. / зап. | **редакция / запусков** — сокращения разворачиваются |
| отпр | **отправлено** |

### Оставляем, но уточняем

| Слово | Уточнение |
|-------|-----------|
| проба | «проба — одно измерение по одному протоколу»; термин продукта, объясняется на «Разработке» и в описании раздела |
| прогон | «прогон — один запуск пробы с сохранением результата» |
| ряд | «ряд — часть прогона, которую считают отдельно: фаза, резолвер или хоп» |
| пресет | остаётся; раздел «Библиотека» переименованию не подлежит — пресет уже объяснён как «именованный тест, который можно повторить» |
| эталон | остаётся (перевод baseline уже сделан) |
| алерт | остаётся: раздел так называется, и в отрасли слово прижилось |

### «Порог» — пять разных вещей

Самая грубая находка. Слово означало:

| Где | Что на самом деле | Как называем |
|-----|-------------------|--------------|
| бейдж условий, шапка журнала | предел разрешения часов измерителя | **порог часов** |
| дашборд | то же | **порог часов** |
| «порог достоверности» на графике | то же | **порог часов** |
| профили окружения | предел, ниже которого измерение считается нормой | **порог профиля** |
| мониторы, сценарии | условие вердикта | **порог** (без уточнения — это основное значение) |

## Что правим по страницам

Полный список мест — ниже. Отмечено ✔ то, что уже сделано.

### Сквозное

- ✔ `Units` подключён к клиенту: факты и ряды получают единицу от измерения.
- ✔ Подпись таблицы рядов берётся у прогона (`Units.TableCaption`).
- ✔ Словарь метрик `MetricWording`: `p95` → «95-й перцентиль», порог целиком —
  «95-й перцентиль меньше 50 мс».
- Единый форматтер миллисекунд вместо шести копий.
- Чипы проб (`ping`, `trace`, `tls`) — показывать `Title`, а не ключ.

### Мониторы

- ✔ Поле порогов: карточка «что такое порог», расшифровка каждого набранного порога
  словами, список доступных метрик с единицами прямо в форме.
- ✔ Формат паузы между оповещениями (`15м`, `2ч`, `1д`).
- «Поднять после, проверок» — сказать, что поднимается алерт.
- SLA, «бюджет ошибок», «покрытие окна» — расшифровать.
- Колонки «Последние проверки» без заголовков.

### Скорость и качество, Локальные тесты

- ✔ Ряды и факты с единицей; подпись таблицы по измерению.
- Выпадающий список направления: `upload`/`download` → «отдача»/«приём».
- Названия проб в списке: MTR, TCP-connect, UDP, iperf3 — расшифровать в описании.

### Анализ пути

- Колонки «мин / медиана / макс / джиттер» — без единицы; нужна подпись таблицы.
- «отпр» → «отправлено».
- MOS, R-фактор, E-модель, MPLS, TTL, ICMP, автономная система — расшифровать.

### Журнал

- ✔ Подпись таблицы рядов и единицы фактов.
- «Сэмплов» → «сырых измерений»; «агрегаты» → «сводки».
- Категории фактов (`dns`, `tls`) — человеческие названия.

### Инспекторы

- Факты без единицы (тот же дефект, третья модель строки).
- Таблица «Разложение» — без заголовков колонок вообще.
- NAT, STUN, AS, IPv6, DNSSEC, резолвер — расшифровать.

### Обнаружение

- «Одновременно» — без единицы (адресов).
- «Что ответило»: ICMP, TCP, ARP, NetBIOS, mDNS, SSDP — расшифровать.
- Нотация `/24` (CIDR) — пояснить в подсказке поля.

### Устройства, Карта сети

- «вендор» → «производитель»; MAC расшифровать.
- «последний раз» — обрезанная подпись колонки.
- Кнопки PNG/SVG/JSON — подписать словами, как в журнале.
- Доля выведенных связей «46 %» — сказать, от чего доля.

### Библиотека

- Таблица параметров показывает внутренние ключи (`count`, `interval`, `size`)
  и голые числа. У проб есть человеческие подписи с единицами — брать их.
- «ред.» и «зап.» — развернуть.

### Отчёты

- «медиана 12.345» без единицы.
- SLA и «бюджет ошибок» — расшифровать.

### Настройки

- ✔ Путь к базе и ключи консоли чипами.
- Мёртвая подсказка `PortHint` (161 — как у всех) написана, но нигде не показана.
- «Порядок перебора» — объяснить, что меньше значит раньше.
- SNMP, v1/v2c/v3, SHA/AES/DES, MIT, NPSL — расшифровать.
- «Отпечаток» — сказать, что это отпечаток сертификата.

### Оболочка окна

- «Уровень 0 — ядро» в шапке: шкала уровней объяснена **только** во временном разделе
  «Разработка», который уйдёт из релиза. После удаления объяснения не останется нигде.
- Чип операции показывает внутреннее имя пробы вместо названия.
- Тип адаптера «loopback» — единственный непереведённый в списке.

## Порядок работ

**Волна A — числа.** ✔ Единицы везде, где показывается измеренное: прогонщик,
журнал, инспекторы, хопы, отчёты. Единый форматтер `Units.Number`/`Units.Measured`
вместо шести копий. Параметры пресета подписываются человеческими подписями проб
с единицами вместо ключей `count`, `interval`, `size`.

**Волна B — слова.** ✔ Перевод по словарю: сэмплы, агрегаты, вендор, Run Drawer,
направления `upload`/`download`. Расшифровки аббревиатур в подсказках: MAC, SNMP,
ICMP/TCP/ARP, NAT/STUN, MOS и R-фактор, джиттер, PNG/SVG/JSON.

**Волна C — недосказанное.** ✔ Заголовки колонок в «Разложении» инспекторов
и в «Последних проверках» мониторов; «уровень 0» объясняется в шапке окна,
а не только во временном разделе; мёртвая подсказка порта SNMP привязана;
пять смыслов слова «порог» разведены — часов, профиля, монитора.

### Осталось на потом

- Внутренние имена проб (`ping`, `trace`, `speedtest`) в чипах журнала, мониторов,
  расписания и библиотеки. Требует доступа к реестру проб в четырёх моделях;
  для сетевого инженера эти имена читаются, поэтому отложено.
- «Уровень 0» в шапке объяснён подсказкой, но раздел «Разработка» с полной
  таблицей возможностей всё ещё временный: при его удалении проверить, что
  объяснение уровней осталось.
