## Принятые решения, которые не следует пересматривать без причины

| Решение | Где обосновано |
|---------|----------------|
| Стек .NET 8 + Avalonia 11 | [ADR-0001](adr/ADR-0001-technology-stack.md) |
| Лицензия MIT | [план §2.1](03-development-plan.md) |
| Npcap не распространяется, только детектируется | [исследование §3.5](02-research.md) — запрещено лицензией NPSL |
| Подпись SSH, а не GPG | [GITHUB-SETUP §2](GITHUB-SETUP.md) — поломка keyboxd в Git for Windows |
| Инструменты — `.cmd` + `sh`, а не PowerShell | [GITHUB-SETUP §3](GITHUB-SETUP.md) — на машине групповая политика `MachinePolicy = AllSigned`, она перекрывает `-ExecutionPolicy Bypass` |
| RTT из системных API не используется никогда | [анализ §8.2 принцип 8](01-analysis.md) — API даёт целые миллисекунды |
| Агент — основа замеров между точками | Решение оператора |
| MVP = Уровень 0 целиком | [план §2.3](03-development-plan.md) |
| Переливка beta → master делается локально | [GITHUB-SETUP §5.3](GITHUB-SETUP.md) — иначе не сработает хук подписи |

сеть 192.168.200.0/24 через Hyper-V vSwitch (даёт p99 в 18× выше p50 — учитывать).
