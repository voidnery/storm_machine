**Приёмка И-1 пройдена:**

| Критерий | Результат |
|----------|-----------|
| Различимость значений | **191 из 200 (95%)**. Целочисленный системный API дал бы единицы процентов |
| Пол собственного шума стека | **0.028–0.043 мс** при бюджете 0.20 мс — запас 4.7–7.2× |
| Аллокации в горячем пути | **941 байт на пробу** при бюджете 4096; сборок второго поколения — 0 |
| Разрешение таймера | 100 нс; порог разрешения на стенде 0.23–0.32 мс |
| Прерывание прогона | Измеренное сохраняется |
| Тесты | **60 из 60** |

**Найдено и исправлено по ходу:**

1. **Первые две пробы были завышены** — 21.7 и 14.5 мс при реальных 0.5–0.7 мс.
   Причина: компиляция асинхронного пути при первом вызове. Калибровка таймера её
   не снимала, потому что использует синхронный путь. Добавлен прогрев на loopback.
2. **Тест шума оказался неустойчивым** — от 9.7% до 22.5% при почти неизменном
   абсолютном джиттере. Ошибка была в знаменателе: доля от loopback, наименьшей
   измеримой величины. Требование переформулировано через явный порог измеримости.
3. **Порог разрешения не вычитается из результатов.** Изначально предполагалось
   вычитать; путь через loopback — не чистые накладные расходы, вычитание давало бы
   систематическую ошибку.

## Ближайшие шаги

**И-2 — зоопарк проб.** Правило трёх примеров: обобщать модель хранения и пресетов
можно только тогда, когда есть несколько разнотипных реализаций.

1. Пробы TCP-connect, UDP, DNS, HTTP(S), TLS
2. Traceroute по TTL — через `IcmpSendEcho2`, raw для этого непригоден
3. Все — через CLI, с разными формами результатов
4. Приёмка: шесть команд дают осмысленный вывод, и различие форм результата видно

## Принятые решения, которые не следует пересматривать без причины

| Решение | Где обосновано |
|---------|----------------|
| Стек **.NET 10 + Avalonia 12** | [ADR-0001](adr/ADR-0001-technology-stack.md) — LTS .NET 8 истекает в ноябре 2026 |
| Встроенная поддержка COM в GUI выключена | Несовместима с обрезкой. Обрезка даёт 35.7 МБ вместо 97.4 МБ. Цена — перетаскивание файлов из проводника |
| Лицензия MIT | [план §2.1](03-development-plan.md) |
| Npcap не распространяется, только детектируется | [исследование §3.5](02-research.md) — запрещено лицензией NPSL |
| Подпись SSH, а не GPG | [GITHUB-SETUP §2](GITHUB-SETUP.md) — поломка keyboxd в Git for Windows |
| Инструменты — `.cmd` + `sh`, а не PowerShell | [GITHUB-SETUP §3](GITHUB-SETUP.md) — на машине групповая политика `MachinePolicy = AllSigned`, она перекрывает `-ExecutionPolicy Bypass` |
| RTT из системных API не используется никогда | [анализ §8.2 принцип 8](01-analysis.md) — API даёт целые миллисекунды |
| Агент — основа замеров между точками | Решение оператора |
| MVP = Уровень 0 целиком | [план §2.3](03-development-plan.md) |
| Переливка beta → master делается локально | [GITHUB-SETUP §5.3](GITHUB-SETUP.md) — иначе не сработает хук подписи |
